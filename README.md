# Focus

A simple focus app built for an ADHD and dyslexia-friendly workday.

- 15-minute work and break blocks with a chime, plus an "I'm in flow" button
- "I'm back" reminder when a break ends
- Day and time always on screen
- Today's Big 3, Right now, and Other tasks
- Voice log ("I did" / "Idea") with a mic button
- Work and Personal spaces; Personal entries are encrypted on the device with your PIN
- Read-aloud on/off, workday stop time, printable daily sheet, log download
- Syncs across devices with Firebase; installs as an app and works offline

Hosted with GitHub Pages. Data lives in the owner's Firebase project.
